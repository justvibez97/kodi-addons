justvibez97 Add-ons (Kodi repository)

Add https://raw.githubusercontent.com/justvibez97/kodi-addons/main/install.zip as a source in Kodi's File manager, then Install from zip file → that source → repo.zip. After that, install add-ons from Install from repository → justvibez97 Add-ons; updates arrive automatically.

  • repository.letterboxd-1.0.1.zip (the repository)
  • plugin.video.letterboxd-1.0.8.zip
  • plugin.video.premiumize.downloader-1.1.1.zip (Debrid Downloader)
  • letterboxd.zip (legacy direct download, no auto-update)
